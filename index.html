🗂 书房与书架

书房是你的电子书主目录（默认 D:\booknook_ebook，可随时更改并自动搬移）。书架就是书房下的文件夹，导入即把书存进书房，「移动到书架」会真实移动文件，书架可任意新建、改名、删除。

📚 书架

全部书籍 / 在读 / 已读完 / 未开始自动分类，支持收藏集、搜索书名作者与排序，进度直接画在封面下沿；卡片可多选（Ctrl / Shift）批量移动与删除，也能直接把书拖到左侧书架整理。

🖍 划线与批注

选中即划线，右键加批注、加书签、复制。亮色与深色主题下划线颜色自动适配，不刺眼、不发闷。

🔖 书签与目录

章节目录一键跳转，书签带摘录。抽屉展开时正文自动重排，不挡字。

🎨 阅读自定义

字号、行距、页边距、亮度随手调；8 种预设字体之外还能选任意已安装的系统字体，书内写死的字体也会被覆盖。浅色 / 羊皮纸 / 深色主题、分页或滚动、宽屏双页，可全局应用，也可为每本书单独设置。

🔍 书内搜索与进度记忆

全书关键词检索，关掉软件再打开，回到上次那本书、那一页，还显示"剩余约几分钟"。

🔒 本地与备份

书籍文件按书房 / 书架真实存放在你指定的目录，元数据与批注也在本机，软件不联网也能完整使用。一键导出 ZIP 备份，换机随时恢复。

技术路线：轻，且不凑合。

没有框架竞态，没有遥测 SDK。该自己写的解析器，就自己写。

Electron 44 + 原生 JS 无 React / Vue，主进程 + 渲染层共 5,580 行自研 JS（不含第三方库）。界面即打开，无构建黑魔法。
自研 MOBI / AZW / AZW3 解析器 PalmDOC 与 HUFF/CDIC 解压、直接按协议读取，不依赖 Calibre 等外部转换工具；真实出版书籍的 AZW3 同样可直读。
EPUB 渲染 + 自研划线层 epub.js 之上重写批注层：ResizeObserver 驱动重排，按背景亮度切换 mix-blend-mode，窗口缩放后高亮不错位。
多列分页引擎 TXT / Markdown 用 CSS 多列排版实现精确翻页，章节独立成页，配合 jschardet 编码探测，GBK 老文件不乱码。
本地 JSON 存储 + ZIP 备份 书籍文件按书房 / 书架真实存放，元数据、进度、批注全部落盘在本机；导出一个 zip 就是全部身家。
electron-builder 打包 便携版 exe 与 NSIS 安装版双产物，端到端冒烟测试（CDP）验证后才发布。

更新说明。

当前版本 v1.4.1（2026-10-12）。

🗂 书房与书架

新增书房 / 书架概念：书房是电子书主目录（默认 D:\booknook_ebook，设置里可改并整体搬移），书架是书房下的一级子目录。导入写进书房，「移动到书架」真实移动文件，书架可任意新建改名；旧版本藏在用户目录的书籍副本首次启动会自动迁入书房。

🖱 批量整理与拖动

书架卡片支持多选（☑ / Ctrl / Shift 区间），可批量移动到书架、批量移除或删除文件；也能直接把书拖到左侧书架上整理，整批拖拽同样支持，落点会高亮。

🔤 字体真正生效

修复部分转换书（epubBuilder、Epubor 等）把字体写死在段落上、导致「换字体没反应」的问题：阅读器设置现在会覆盖书内样式，代码块仍保留等宽。预设字体扩到 8 种，并自动列出已安装的系统字体；新增「恢复默认显示」与「恢复默认阅读设置」。

🧩 交互细节

点空白处即可收起字体面板与右键菜单（含 EPUB 正文区域）；修复「应用到所有书籍」后设置回退、新建书架后设置页书架数不刷新等问题。
